# BratikVPN

Каркас Windows-клиента с PyQt6 для управления установленным OpenVPN.

## Запуск

1. Установите OpenVPN и подготовьте `.ovpn`-конфигурацию с разрешением на её использование.
2. Установите зависимости:

```powershell
py -m pip install -r requirements.txt
```

3. Укажите путь к `openvpn.exe` в переменной окружения `BRATIKVPN_OPENVPN` или используйте путь по умолчанию.
4. Добавьте серверы и пути к `.ovpn`-файлам в `assets/servers.json`.
5. Запустите:

```powershell
py main.py
```

OpenVPN обычно требует запуска с правами администратора и установленного TUN/TAP-драйвера. Этот MVP не содержит собственного VPN-протокола и не реализует kill switch: сначала проверяется стабильное подключение через официальный OpenVPN-клиент.
