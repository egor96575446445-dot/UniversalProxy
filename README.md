# Universal Proxy Server

**Универсальный SOCKS5 / HTTP-прокси-сервер для Windows.**

Этот прокси-сервер позволяет перенаправлять интернет-трафик через него, поддерживая как SOCKS5, так и HTTP-протоколы (CONNECT, GET, POST). Он идеально подходит для настройки в браузерах (Яндекс, Chrome, Firefox, Edge) или в любых других приложениях с поддержкой прокси.

## Возможности

*   **Два протокола в одном:** Автоматически распознаёт и обрабатывает как SOCKS5, так и HTTP-запросы.
*   **Аутентификация:** Защищён логином и паролем для предотвращения несанкционированного доступа.
*   **Многопоточность:** Способен обрабатывать до 100 подключений одновременно.
*   **Логирование:** Ведёт подробный журнал всех подключений и ошибок в файл `proxy.log`.
*   **Готов к работе:** Поставляется в виде одного `.exe`-файла, не требующего установки Python.

## Быстрый старт

### Запуск
1.  Скачайте файл `UniversalProxy.exe`.
2.  Запустите его двойным кликом. Откроется консольное окно с логами.
3.  Настройте ваше приложение (например, браузер) на использование прокси-сервера с адресом `127.0.0.1` и портом `1080`.

### Настройка по умолчанию
*   **Адрес:** `127.0.0.1`
*   **Порт:** `1080`
*   **Тип:** `SOCKS5` или `HTTP`
*   **Логин:** `proxyuser`
*   **Пароль:** `proxypass`
